# OpenStreetMap fixtures

Real Overpass responses for the gateway's basemap tests, shrunk by `tools/make_osm_fixture.py`.

- `kyiv-30km.json.gz`: the gateway's query (`gateway/alert_gateway/overpass.py`) for a 30 km map
  around central Kyiv (50.4501, 30.5234), fetched 2026-11-15.
